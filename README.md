# X屏蔽词助手

一个面向中文用户的 Chrome / Edge Manifest V3 扩展，帮助你把常见的中文广告、引流和营销骚扰词添加到 X 的屏蔽词。

## 它解决什么问题

X 的屏蔽词需要逐条手动添加。清净词内置一组经过整理的常见中文骚扰词，打开 X 的屏蔽词设置页后，会列出尚未添加的词。你确认列表后，点击一次按钮即可逐条添加。

- 内置中文广告与引流词
- 默认全选，添加前可取消勾选
- 只添加，不删除已有屏蔽词
- 不读取、不上传 Cookie、账号信息或页面内容
- 不调用 X 私有 API，不执行远程 JavaScript
- 词包和用户自定义内容只保存在本机

> 屏蔽词可能误伤正常内容。请先检查列表，再确认添加。

## 使用方法

1. 安装扩展后，点击浏览器工具栏中的“清净词”图标。
2. 点击“开始添加”。
3. 扩展会把助手卡片插入 X 屏蔽词设置页面的内容区域，不遮挡页面。
4. 点击“查看待添加词条”检查本次将添加的内容。
5. 点击“一键添加 N 个词”，等待页面显示完成状态。
6. 添加完成后，助手会重新检查剩余词条。

如果助手卡片没有出现，请确认当前地址是 X 的屏蔽词设置页，并刷新页面再试。

## 没有 Chrome 商店权限时如何安装

本项目提供无需商店的“加载已解压扩展”安装方式，适用于无法访问 Chrome Web Store 的环境。

### Chrome

1. 下载仓库中的 ZIP，或点击 GitHub 的 `Code → Download ZIP`。
2. 解压到一个不会随意删除的目录，例如 `~/Applications/qingjingci/`。
3. 打开 `chrome://extensions`。
4. 开启右上角的“开发者模式”。
5. 点击“加载已解压的扩展程序”。
6. 选择解压后的项目目录，也就是包含 `manifest.json` 的目录。
7. 安装完成后，将“清净词”固定到工具栏。

### Edge

1. 下载并解压 ZIP。
2. 打开 `edge://extensions`。
3. 开启“开发人员模式”。
4. 点击“加载解压缩的扩展”。
5. 选择包含 `manifest.json` 的目录。
6. 将“清净词”固定到工具栏。

### 安装时找不到 manifest.json

不要选择 ZIP 文件本身，也不要选择外层下载目录。选择的目录必须直接包含：

```text
manifest.json
popup.html
content.js
packs/
```

### 浏览器提示扩展可能被停用

“加载已解压扩展”是浏览器的开发者安装方式。浏览器重启或策略更新后，可能要求重新启用或重新加载。企业设备如果禁止开发者扩展，需要管理员允许；这不是插件本身可以绕过的限制。

## 词包资源

默认词条随插件内置，安装后不需要先下载或配置词包。仓库中的 `packs/` 目录是可版本管理的静态资源，后续可以在不改变插件主体的情况下增加更新和镜像能力。

远程资源只允许作为 JSON 数据使用，并且必须经过格式、数量和长度校验；插件不会加载或执行远程脚本。

## 开发检查

这是一个无构建步骤的原生 Manifest V3 扩展：

```bash
node --check popup.js
node --check content.js
python3 -m json.tool manifest.json >/dev/null
```

## 隐私与权限

扩展仅声明：

- `storage`：保存内置词条和用户自定义词条
- `tabs`：打开 X 屏蔽词设置页
- `https://x.com/*`：只在 X 页面运行，其中实际注入范围仅为屏蔽词设置页

扩展不提供账号登录，不读取 Cookie，不上传数据，不包含广告和统计 SDK。
