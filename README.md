# X屏蔽词助手

一个面向中文用户的 Chrome / Edge Manifest V3 扩展。它把统一维护的广告、引流和营销骚扰词添加到 X 原生屏蔽词，并提供可选的桌面端本地评论过滤。

## 它解决什么问题

X 的屏蔽词需要逐条添加。扩展会显示已经添加和仍待处理的词；你确认后点击一次，插件在后台逐条完成入口点击、真实文本输入、保存和返回列表验证。

桌面端可选开启本地评论过滤，按透明规则识别黄色推广、联系方式引流、重复模板和低信息机器人回复。它只影响当前浏览器，不会同步到手机；默认关闭。

- GitHub 远程中文词包，统一维护并缓存到本机
- 内置词包作为离线 fallback
- 插件只添加，不删除已有屏蔽词
- 不读取 Cookie 或账号凭据；页面内容只在本机处理，不上传
- 不调用 X 私有 API，不执行远程 JavaScript
- 词包、过滤设置、白名单和统计只保存在本机
- 评论过滤默认关闭；开启后也只在当前浏览器本地处理，不会同步到手机
- 评论过滤支持折叠、隐藏和模糊三种方式
- 评论过滤支持白名单、重复模板识别和自定义关键词/正则

> 屏蔽词可能误伤正常内容。请先检查待添加列表，再确认添加。

## 使用方法

### 添加 X 原生屏蔽词

1. 点击扩展图标，选择“开始屏蔽”。
2. 在 X 设置页检查“待添加词条”。
3. 点击“开始屏蔽 N 个词”。
4. 插件会自动逐条添加；失败时停止并显示具体词条和原因。

批量期间 Chrome 会显示扩展正在调试当前标签页，这是插件发送真实输入所需的提示；完成或失败后会立即断开。这些词保存到 X 原生设置，所以手机端也会生效。

### 可选：过滤时间线和评论区

1. 打开 X 时间线或任意帖子详情页。
2. 点击扩展图标，展开“可选：过滤时间线和评论区”。
3. 手动开启后选择强度和隐藏方式。
4. 遇到误判时点击“显示”，或把账号加入信任名单。

该功能只处理当前浏览器已经加载的内容，不替代 X 原生屏蔽词。

如果助手卡片没有出现，请确认当前地址是 X 的屏蔽词设置页，并刷新页面再试。

## 没有 Chrome 商店权限时如何安装

本项目提供无需商店的“加载已解压扩展”安装方式，适用于无法访问 Chrome Web Store 的环境。

### Chrome

1. 下载仓库中的 ZIP，或点击 GitHub 的 `Code → Download ZIP`。
2. 解压到一个不会随意删除的目录，例如 `~/Applications/qingjingci/`。
3. 打开 `chrome://extensions`。
4. 开启右上角的“开发者模式”。
5. 点击“加载已解压的扩展程序”。
6. 选择解压后的项目目录，也就是包含 `manifest.json` 的目录。
7. 安装完成后，将“X屏蔽词助手”固定到工具栏。

### Edge

1. 下载并解压 ZIP。
2. 打开 `edge://extensions`。
3. 开启“开发人员模式”。
4. 点击“加载解压缩的扩展”。
5. 选择包含 `manifest.json` 的目录。
6. 将“X屏蔽词助手”固定到工具栏。

### 安装时找不到 manifest.json

不要选择 ZIP 文件本身，也不要选择外层下载目录。选择的目录必须直接包含：

```text
manifest.json
popup.html
content.js
packs/
```

### 浏览器提示扩展可能被停用

“加载已解压扩展”是浏览器的开发者安装方式。浏览器重启或策略更新后，可能要求重新启用或重新加载。企业设备如果禁止开发者扩展，需要管理员允许；这不是插件本身可以绕过的限制。

## 词包资源

词包权威来源是：

```text
https://raw.githubusercontent.com/sogud/x-muted-words/main/packs/manifest.json
```

插件每 24 小时自动检查一次，也可以在弹窗中手动更新。远程词包只接受允许范围内的 JSON 数据，并校验词条数量、长度和中文内容；网络不可用时使用本机打包的词包和缓存。插件不会加载或执行远程脚本。

维护词包时只修改 `packs/manifest.json` 和 `packs/*.json`；插件会自动读取本地词包、显示分类和词数，再合并远程版本。`rules.js` 不再维护屏蔽词副本。

```bash
node --check rules.js

node --check content.js
node --check background.js
node --check reply-filter.js
node tests/background-import.test.mjs
node tests/rules.test.mjs
python3 -m json.tool manifest.json >/dev/null
```

## 隐私与权限

扩展仅声明：

- `storage`：保存内置词条和用户自定义词条
- `tabs`：打开 X 屏蔽词设置页
- `debugger`：批量期间只连接当前 X 设置页，执行页面控件定位、真实文本输入和点击；完成或失败后立即断开，不读取网络、Cookie 或浏览器存储
- `https://x.com/*`：屏蔽词助手卡片只注入设置页；可选评论过滤只处理当前浏览器页面
- `https://raw.githubusercontent.com/sogud/x-muted-words/*`：只读取经过校验的 JSON 词包

扩展不提供账号登录，不读取 Cookie，不上传数据，不包含广告和统计 SDK。
